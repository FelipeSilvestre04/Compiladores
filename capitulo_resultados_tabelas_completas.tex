\chapter{Resultados e Testes}
\label{chap:resultados}

Neste capítulo, são apresentados os resultados práticos da compilação de três programas escritos em C-: o algoritmo de Euclides para cálculo do máximo divisor comum, o fatorial recursivo e o algoritmo de ordenação por seleção. Os exemplos demonstram o fluxo completo de compilação, incluindo a geração do código intermediário em quádruplas, a tradução para assembly e a codificação das instruções em palavras binárias de 32 bits.

Em cada caso, o código-fonte é apresentado antes da tabela de correspondência. Em seguida, a tabela completa relaciona as quádruplas geradas, as instruções assembly correspondentes e o código binário produzido. As linhas de rótulo no assembly não possuem palavra binária associada, pois representam apenas endereços simbólicos resolvidos durante a geração do código executável.

\section{Algoritmo de Euclides: Máximo Divisor Comum}
\label{sec:res_gcd}

O primeiro caso de teste é o algoritmo de Euclides, implementado com chamada recursiva. Esse exemplo exercita comandos condicionais, operações aritméticas, divisão inteira, chamada de função com dois argumentos, retorno de valor e comandos de entrada e saída.

\subsection{Código-fonte}

\begin{lstlisting}[language=C, caption={Código-fonte do algoritmo de Euclides para cálculo do MDC.}, label={lst:gcd_fonte}]
/* Um programa para calcular o mdc
   segundo o algoritmo de Euclides. */

int gcd(int u, int v)
{
    if (v == 0)
        return u;
    else
        return gcd(v, u - u / v * v);
}

void main(void)
{
    int x;
    int y;

    x = input();
    y = input();

    output(gcd(x, y));
}
\end{lstlisting}

\subsection{Análise comparativa}

No algoritmo de Euclides, as quádruplas de comparação e desvio representam a condição de parada da recursão. A expressão \texttt{u - u / v * v} é decomposta em operações intermediárias de divisão, multiplicação e subtração. A chamada recursiva é representada por quádruplas de passagem de parâmetro e chamada de função, que são traduzidas para instruções de pilha e para a instrução \texttt{JAL}. O retorno utiliza \texttt{LOAD\_STACK}, \texttt{STORE\_STACK} e \texttt{JR} para restaurar o endereço de retorno e disponibilizar o valor calculado.

\section{Algoritmo de Fatorial Recursivo}
\label{sec:res_fact}

O segundo caso de teste é o fatorial recursivo. Esse exemplo exercita comando condicional, chamada recursiva com um argumento, subtração, multiplicação, retorno de valor e comandos de entrada e saída.

\subsection{Código-fonte}

\begin{lstlisting}[language=C, caption={Código-fonte do algoritmo de fatorial recursivo.}, label={lst:fact_fonte}]
int fact(int n)
{
    if (n <= 0) {
        return 1;
    }

    return n * fact(n - 1);
}

void main(void)
{
    int n;

    n = input();
    output(fact(n));
}
\end{lstlisting}

\subsection{Análise comparativa}

No fatorial recursivo, a condição \texttt{n <= 0} é traduzida para uma comparação seguida de desvio condicional. O caso base gera o carregamento imediato do valor \texttt{1} e o retorno da função. No caso recursivo, o compilador gera a subtração \texttt{n - 1}, empilha o argumento, realiza a chamada para \texttt{fact} e utiliza o valor retornado na multiplicação final. As instruções de pilha preservam o endereço de retorno e permitem que cada ativação da função mantenha seu próprio fluxo de execução.

\section{Algoritmo de Ordenação: Selection Sort}
\label{sec:res_sort}

O terceiro caso de teste é o algoritmo de ordenação por seleção. Esse exemplo exercita vetor global, passagem de vetor como parâmetro, acesso indexado à memória, laços de repetição, chamada de função, variáveis locais e comandos de entrada e saída.

\subsection{Código-fonte}

\begin{lstlisting}[language=C, caption={Código-fonte do algoritmo de ordenação por seleção.}, label={lst:sort_fonte}]
/* programa para ordenacao por selecao de
   uma matriz com dez elementos. */

int vet[10];

int minloc(int a[], int low, int high)
{
    int i;
    int x;
    int k;

    k = low;
    x = a[low];
    i = low + 1;

    while (i < high) {
        if (a[i] < x) {
            x = a[i];
            k = i;
        }

        i = i + 1;
    }

    return k;
}

void sort(int a[], int low, int high)
{
    int i;
    int k;

    i = low;

    while (i < high - 1) {
        int t;

        k = minloc(a, i, high);
        t = a[k];
        a[k] = a[i];
        a[i] = t;
        i = i + 1;
    }
}

void main(void)
{
    int i;

    i = 0;

    while (i < 10) {
        vet[i] = input();
        i = i + 1;
    }

    sort(vet, 0, 10);

    i = 0;

    while (i < 10) {
        output(vet[i]);
        i = i + 1;
    }
}
\end{lstlisting}

\subsection{Análise comparativa}

No algoritmo de ordenação, as operações sobre vetores exigem tratamento adicional na etapa de geração de código. Quádruplas como \texttt{(LOAD, a, \$t0, \$t1)} e \texttt{(STORE, \$t1, a, \$t0)} representam acessos indexados. Na tradução para assembly, esses acessos podem ser expandidos em mais de uma instrução binária, pois o endereço efetivo precisa ser calculado a partir do endereço-base do vetor e do índice. Quando o vetor é recebido como parâmetro, o valor associado ao identificador representa o endereço-base utilizado para acessar os elementos.

\section{Síntese dos Resultados}

Os três testes cobrem os principais recursos implementados no compilador. O exemplo do máximo divisor comum valida chamadas recursivas com múltiplos argumentos e expressões aritméticas compostas. O exemplo do fatorial valida recursão simples, caso base e propagação do valor de retorno. O exemplo de ordenação valida laços, vetores, passagem de vetor como parâmetro e expansão de acessos indexados para instruções executáveis no processador-alvo.
