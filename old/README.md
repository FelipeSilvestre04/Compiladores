# Old / Archived Files

Esta pasta guarda arquivos que foram retirados do caminho ativo do projeto sem apagar nada.

- `legacy/`: entregas e atividades antigas.
- `root_artifacts/`: zips, testes soltos e rascunhos antigos da raiz.
- `compiler_generated/`: arquivos gerados ou versões alternativas antigas do pipeline do compilador.
- `stale_binaries/`: executáveis Windows antigos para evitar uso acidental.
- `processor_backups/`: arquivos `.bak`, `.old` e variantes antigas de módulos Verilog.
- `processor_waveforms/`: waveforms antigas do Quartus.
- `processor_logs/`: traces/logs grandes.
- `quartus_generated_stale/`: bancos, simulações e saídas geradas pelo Quartus. O Quartus recria isso na próxima compilação.
- `docs_old/`: relatórios antigos preservados.
